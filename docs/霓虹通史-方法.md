# 《三国：一口气讲完》复刻方法

目标形态：高密度 2D 角色插画 + 动态排版 + 信息图表 + 节拍剪辑。
记忆点：复古二次元、霓虹配色、快切、洗脑循环、歌词式动态大字、密集视觉梗。

本机没有 AE，所以整条链路换成「**程序化合成音乐 + AI 插画 + Canvas 逐帧 + ffmpeg**」。
换成 AE 也只是换一个合成器，下面四层的结构完全一样。

---

## 第 0 步：把爆款拆成四层（别学表皮，学结构）

| 层 | 爆款里观察到 | 本片落法 |
|---|---|---|
| ① 资产层 | 一套统一的角色/场景插画 | ImageGen 出 16 张，统一提示词锁死视觉语言 |
| ② 排版层 | 大字 + 年份 + 图表压在画面上 | Canvas 画逐字大字、数字块、对比条、四角框 |
| ③ 节奏层 | 每一刀都踩鼓点 | 128BPM，一幕 10 拍，所有动画以「拍」为单位 |
| ④ 剪辑层 | 快切、闪白、弹跳 | 幕间硬切 + 幕内 0.3s 斜切 wipe + 每拍脉冲/故障切片 |

关键判断：**先定音乐节拍，再排画面**，不是先画素材再配乐。
所以第 1 步是合成 BGM，第 2 步才是生成素材。

---

## 第 1 步：程序化合成洗脑 BGM（约 60 行 numpy）

`audio/build_bgm.py` —— 128 BPM / 4-4 / 40 小节 = 75.000s，A 小调五声（宫调式，听得懂的"中国味"）。

```
拍长 spb = 60/128 = 0.46875s      小节 = 1.875s      一幕 = 2.5 小节 = 4.6875s
16 幕 × 4.6875s = 75s
```

结构（按 8 小节一段）：intro → A（加鼓与 riff）→ B（更满）→ break（撤底鼓上 16 分琶音）→ A'（全奏）→ 收。
和弦循环 `Am - F - C - G`（根音偏移 `[0,-4,-9,-2]` 半音）。

音色全是波形 + 包络，没有任何采样：
- **底鼓**：`sin` 频率从 110×2.6 滑到 110×0.55 + 一小撮噪声击打（每拍）
- **军鼓**：190Hz `tri` + 白噪 `band` 短衰减（2、4 拍）
- **hi-hat**：白噪 + 极短包络（8 分音符），偶尔开镲过门
- **贝斯**：`square` + 低通，八分蹦根音/五度
- **主 riff**：`saw` 双振荡微失谐（detune 0.6%）+ 低通 2600，8 小节动机循环
- **pad**：`tri` 三和弦长音慢起慢落
- 总线：`tanh` 软削波 → 四抽头延迟混响 → 归一化

**导出卡点表**（这是给画面用的关键产物）：

```json
{ "bpm": 128, "spb": 0.46875, "bar": 1.875, "total": 75.0,
  "kick": [0.0, 0.46875, ...], "snare": [...], "hat": [...], "beat": [...] }
```

动画里每帧算出「幕内拍号」`beat = lt / spb` 和「拍内相位」`bp = beat - floor(beat)`，
`pulse = (1-bp)^6` 就是每一下鼓的冲击 —— 闪白、缩放、故障全挂在这个 `pulse` 上。

## 第 2 步：AI 插画资产（16 张，一张 5-10 积分）

统一提示词模板（复刻感全在这 40 个字里）：

```
Retro 1990s anime cel-shaded illustration of <主体>;
Bold black ink lineart with neon magenta and cyan rim glow, deep indigo-black background,
halftone dots, film grain, high contrast; <光效>;
no text, no letters, no watermark, no logo
```

- `size 1024x1536`（2:3，正好配 1080×1920 竖屏 cover）
- 每张的主体描述写**画面事实**（谁在哪干什么、周围有什么），不写情绪形容词；配色靠 `neon magenta and cyan rim glow` 统一
- 16 幕与历史事件一一对应：184 黄巾 → 189 董卓焚洛 → 190 讨董联盟 → 200 官渡 → 208 赤壁 → 214 入川 → 219 定军山 → 219 麦城 → 220 受禅 → 222 夷陵 → 223 白帝城托孤 → 225 七擒孟获 → 234 五丈原 → 249 高平陵 → 263 阴平灭蜀 → 280 三家归晋

**两个必须踩过的坑**（不写会重做一遍）：

1. `output_dir` 传不同的目录时**只生效最后一个**，四张图会全挤进同一个目录。
2. 同一批并行调用若落在同一秒，文件名撞车 → **直接丢图**（丢的那张要补生成）。
   → 正确做法：按工具返回的完整路径（`Retro_..._HH-MM-SS.png`，文件名唯一）逐个 mv 成 `assets/sNN/0.png`。
   **绝不能按 mtime 排序**，生成耗时不等，mtime 顺序和返回顺序完全不是一回事。

## 第 3 步：Canvas 动效（全部以「拍」为单位）

`index.html` / `timeline.js` / `render.js`（都在工程根目录，素材走 `assets/`）。
竖屏 1080×1920，`drawFrame(t)` 接受全局时间 → 任意 t 可重放（确定性，分段渲染的前提）。

```js
const beat = lt / TL.spb;        // 幕内拍号 0→10
const bp   = beat - Math.floor(beat);
const pulse = Math.pow(1 - bp, 6);   // 每拍冲击，衰减很快 → 卡点感
```

每一幕 `drawScene(sc, lt, t, gi)` 的七个动作层：

1. **背景**：三色渐变 + 主色光斑（跟着 pulse 呼吸）+ 霓虹透视网格 + 地平线亮带
2. **主图**：斜切 wipe 入场（0.3s，前沿亮边）+ 缩放弹跳 `1.14→1.0` + 每拍横向错位（故障切片：`bp < 0.1` 时把图切 4 条横带各偏移几十像素）
3. **年份**：196px 巨字从上砸入 + 卡点拉出的横线
4. **地名**：右上竖排单字循环（每行间隔 96px）
5. **大字**（记忆点核心）：`popLine()` 逐字弹出，每字延迟 0.042s、窗口 0.26s，`easeOutBack` 过冲；`shadowBlur = size*0.5` 出霓虹辉光
6. **信息图表**：大数字块 + 说明 + 两行对比条（从 0 长出，逐行延迟 0.16s）
7. **覆盖层**：扫描线 + 噪点 + 暗角 + 四角 L 框 + 幕号 `01/16` + 全局进度条；出幕 0.26s 闪白

幕与幕之间**硬切**（短视频的爽点），靠「出幕 0.26s 闪白」+「入场 0.3s wipe」衔接。

## 第 4 步：渲染与合成

`pipeline/render.py`（Playwright + 本地 http + 逐帧截图）：

```bash
uv run --with playwright python render3.py --fps 30 --from 0 --to 18.75 --out ../渲染/w0.mp4
```

- 本地 http 起在 `三国通史动画/`（root），页面 `/index.html`，素材 `assets/…` —— **路径必须全 ASCII**
- **`--no-proxy-server`**：Chromium 会继承系统代理（本机如有代理软件，残留规则会让本地请求也走代理），连 127.0.0.1 都被拒，页面永远 boot 不完
- **`ThreadingTCPServer + request_queue_size=128`**：默认 backlog=5 撑不住 16 张 3MB 图的并发
- **必须等 16 张立绘 decode 完再开始渲**（`wait_for_function` 式的 Promise），否则整幕只画得出背景

分段：4 段 × 4.6875s 边界切（0 / 18.75 / 37.5 / 56.25 / 75），每段独立 chromium+ffmpeg；
拼接 `ffmpeg -f concat -safe 0 -i list.txt -c copy -movflags +faststart`（**清单里必须是相对文件名，且 cwd 就在片元目录**）。

混音（画面本身无声，loudnorm 顺手把响度压平）：

```bash
ffmpeg -i 成片.mp4 -i audio/bgm.m4a -c:v copy -c:a aac -b:a 192k \
       -af "loudnorm=I=-14:TP=-1.5:LRA=11" -shortest -movflags +faststart 最终.mp4
```

## 第 5 步：审片抓到的真问题（最重要的一条）

第一版成片渲染完，llm 自测没问题、16 幕总览图也全都到位，但**派独立审片人程序化复核后判「不能交付」**，抓出：
两处 **2 秒完全硬冻**（11.5–13.5s 酸枣、44.5–46.5s 夷陵，变化像素 0.00%，连噪点都停），另有 4 处 1 秒级近静止。

**根因（这是可以写成通用规律的一条）**：

> 靠 BPM pulse 驱动画面的动画，pulse 是 `(1-bp)^6` —— 每拍只有前 ~48% 时间有值，
> **拍末那 52% 的时间 pulse 恒等于 0**。如果画面上只有一个 pulse，观众眼里的「静止时长」就是
> 「每拍一半时间」，音乐在砸鼓而画面不动，会被 100% 判成卡帧。

所以凡是「脉冲 + 静态资产」的方案，都必须额外铺一层 **持续运动底（persistent motion floor）**，
四条腿缺一不可：

| 层 | 本片加的持续运动 | 周期 |
|---|---|---|
| 背景 | 透视网格纵向线摆 + 横线上下起伏推进 | 0.75s / 0.42s |
| 光斑 | radial 渐变圆心沿 Lissajous 缓慢游走 | 0.37s / 0.29s |
| 主图 | 慢呼吸缩放 `sin(t*1.75)` + 横摆 `sin(t*0.51)` + 纵移 | 3.6s / 12s |
| 前景 | **28 粒上浮尘埃**（有辉光、可循环）+ **CRT 滚动光带** | 16s / 6.25s |

再加两笔便宜的：地名/小注的 alpha 与 y 带 `sin(t*…)` 呼吸，噪点从 220 粒加到 320 粒。

**自测指标**（审片人用的口径，很好用，建议每次交付前都跑）：
抽帧 → 相邻 0.5s 两帧作差 → 变化像素占比。
`占比 <0.3% 记为近静止`、`=0% 记为硬冻`。本片修完前：**≥2s 硬冻 2 处 + 1s 级 4 处**；修完：**0**。

另两个小坑（都是竖排版面特有）：

- **右上小注必须右对齐**：`glowText(..., 'right')` + `x = W-68`。
  用 `left` + 绝对 x 时，8 字以上的小注（如「自威震华夏到身死」40px×9 字 = 360px，从 x=812 起）
  会溢出 1080 宽被右边切掉。
- **底部三行要算总高**：副标 1655 / 对比条 1720+1816 / 幕号基线 1858。
  原来对比条第二根在 1846，直接压住幕号 `01/16`。

## 踩坑清单（本片实测）

| 坑 | 现象 | 解法 |
|---|---|---|
| 中文 URL | `engine/scenes/…`（非 ASCII 目录） 一律 404，画面「没图」 | 入口与素材全 ASCII：`index.html` 放根、`assets/` |
| wipe 前沿算错 | 遮罩成 x≈1209–1339 的窄带，主图整块在画面外 | 前沿 `= W*1.25*wq`，`wq=1` 时稳盖满 |
| 立绘未 decode | 前几幕只有背景网格 | 渲染前等 16 张 `complete && naturalWidth` |
| ImageGen 并行丢图 | 同秒两张撞名覆盖 | 按返回路径逐个 mv |
| `mtime` 排序编号 | 图与事件对不上 | 只认返回的 `HH-MM-SS` 文件名 |
| concat 清单路径 | 绝对路径/上层相对都 `No such file` | 相对文件名 + cwd 在片元目录 |
| 帧目录不分段 | ffmpeg `%05d` 把整个 `_帧` 全吞进每一段，四段都变 75s | 帧目录按段隔离 `_帧_{idx0}` |
| `idx0` 先用后定义 | `frames = f'{a.frames}_{idx0}'` 写在 `idx0 = int(a.f0*fps)` 之前 → `UnboundLocalError` | 赋值提到使用之前（重构时最容易犯） |
| chrome-headless-shell 直连 | `network service crashed`（子进程被杀），页面 JS 根本不执行，帧数一直 0 | 换 playwright 控制 chromium（本机 `pip install playwright` 走代理要 ~20 分钟，先挂后台再干别的） |
| 页面白屏 ≠ JS 报错 | headless 截图白屏，先分清「JS 没跑」还是「图没加载」 | 页面里加 `window.onerror → fetch('/log?m=…')` 回传日志，服务器打印 |
| canvas `shadowBlur` 慢 | 每帧 28 个带辉光粒子，渲染慢 5 倍（一段 1.5 分钟 → 18 分钟） | 用「外圈低 alpha 大圆 + 内圈实心圆」模拟辉光，或接受慢 |
| 音频响度断层 | 后半段 RMS 突然 +3dB、峰值 1.105 溢出 | 混音时 `loudnorm=I=-14:TP=-1.5:LRA=11` 一并压平 |

## 这套方法的可迁移点

换任何题材只需改三处：`timeline.js` 的 16 幕文案与配色（hue），`assets/s01…s16` 的图，`build_bgm.py` 的 BPM/小节数。
动效、卡点、渲染管线一行不用动。

要更短/更长：改 `TL.total` 与幕数即可 —— 但幕数 × 2.5 小节要等于 BGM 小节数，否则首尾对不上拍。
