# 三国人物选题研究 —— 下一批还能拍谁

> 研究日期：2026-10-12　｜　服务对象：水墨人物系列（约 25s / 1920×1080 / 8 句旁白 / 竖屏发布）
> 触发：用户点名「左慈」，要求深挖还有哪些三国人物可继续制作动画

---

## 一、结论速览（先看这三条）

1. **最大的机会不是「补大人物」，而是「补类型」。** 已做 12 人全是男性武将/谋臣，**女性 0、奇人异士 0**——这是两个结构性空白，比再拍一个关羽更有辨识度。
2. **「左慈」是被严重低估的选题**，且与水墨媒介天然契合：幻术 = 墨色变幻、留白、分身，正是水墨最擅长的语言，而不必再画一遍千篇一律的战场。他同时补上了「奇人异士」这条全新线。
3. **行业在往冷门走。** 2026 年追光《三国第一部：争洛阳》刻意避开赤壁、官渡这些「被嚼烂」的名场面，选极少影视化的 189 年洛阳乱局、以青年曹操视角破壁——**冷门切口既是科普也是差异化**，这恰好是本系列已有的调性优势。

## 三、选题五维标准（约 25s 水墨生平动画）

| 维度 | 要求 | 说明 |
|---|---|---|
| ① 视觉记忆点 | 至少 1 个「一画就认得」的画面 | 水墨动画靠画面钩子，不靠台词 |
| ② 生平弧光 | 起—转—终，25 秒能讲完 | 忌人物过散、无终局 |
| ③ 情感钩子 | 悲 / 烈 / 奇 / 憾，四选一 | 本系列以「悲、烈」为主，可扩「奇」 |
| ④ 差异化 | 不与已做 12 人撞型 | 尤其避免第 3 个「忠而见戮」的谋士 |
| ⑤ 素材密度 | 演义回目 + 正史都有料 | 保证 8 句文案有实料可写 |

## 五、左慈专题（用户点名，重点展开）

### 5.1 故事线（《三国演义》第六十八回「甘宁百骑劫魏营　左慈掷杯戏曹操」）

外形：**眇一目、跛一足，头戴白藤冠，身穿青懒衣**，道号**乌角先生**，庐江人，字元放。于西川嘉陵峨嵋山学道三十年，雷震石壁得《遁甲天书》三卷（天遁腾云、地遁穿石、人遁变身）。

连环幻术递进（天然的分镜节奏）：

1. 替脚夫各挑柑橘五里 → 曹操剖开**全是空壳**
2. 左慈亲剖 → **皆有肉，其味甚甜**
3. 宴前画龙于粉墙，袍袖一拂，**龙腹自开，取出龙肝**（鲜血尚流）
4. 大盆浇水 → **顷刻牡丹双花**
5. 鱼池垂钓 → **数十尾松江四腮鲈鱼**
6. 金盆覆衣 → **紫芽姜满盆**，盆中现《孟德新书》
7. 玉簪**将酒杯一分为二**，自饮一半奉操；操不饮，掷杯空中 → **化为白鸠绕殿而飞**，人已不见
8. 遁入羊群 → 许褚尽杀群羊 → **施法尽活**
9. 曹操斩三四百个「左慈」→ 人人颈腔**青气冲天，聚成一左慈**，招白鹤骑坐大笑：「**土鼠随金虎，奸雄一旦休！**」
10. 所斩之尸**手提其头奔上演武厅打曹操**，曹操惊倒于地 → 落病根 → 建安二十五年庚子（220）曹操果薨

### 5.2 为什么左慈天然适配水墨

| 幻术元素 | 水墨语言 | 效果 |
|---|---|---|
| 掷杯化白鸠 | 墨点化鸟、笔断意连 | 一秒变形，最出彩的转场 |
| 画龙取肝 | 泼墨成龙、笔走龙蛇 | 龙是水墨的母语 |
| 分身数百、青气聚形 | 留白 + 淡墨渲染 | 分身用淡墨重叠，收束为一笔浓墨 |
| 盆中牡丹、池中鲈鱼 | 没骨花鸟 | 与战斗题材完全不同的美感 |
| 遁入羊群 | 墨块群化 | 趣味性 |

**关键**：这是全系列第一个**不需要画战场**的角色。前 12 人都绕不开刀马，左慈能把水墨的「变幻」彻底放出来，是本系列视觉上的一次升级机会。

### 5.3 八句文案草案（贴合本系列 8 句旁白格式）

| # | 文案 |
|---|---|
| 1 | 庐江左慈，字元放，眇一目，跛一足，白藤冠，青懒衣，道号乌角先生。 |
| 2 | 峨嵋山学道三十年，天雷震碎石壁，得《遁甲天书》三卷：天遁、地遁、人遁。 |
| 3 | 孙权贡曹四十担柑橘，他替脚夫各挑五里；曹操亲剖，壳内空无一物。 |
| 4 | 他接过刀再剖，果肉饱满，其味甚甜。曹操疑其妖，他只笑而不辩。 |
| 5 | 宴上画龙取肝，泼水成牡丹，垂钓得松江四腮鲈，覆盆得紫芽姜。 |
| 6 | 拔簪分酒，自饮一半，一半奉曹。曹不饮，他掷杯空中，化为白鸠绕殿而飞。 |
| 7 | 遁入羊群，许褚尽杀之，他尽活之；曹斩三四百分身，青气冲天，聚成一左慈，骑白鹤笑曰—— |
| 8 | 「土鼠随金虎，奸雄一旦休。」是年曹操惊倒成疾；建安二十五年庚子，操果薨。 |

### 5.4 注意事项

- **史实边界**：左慈**确有其人**（《后汉书·方术列传》有传，庐江人，曹操「聚而禁之」的方士之一，葛玄之师，对道教灵宝派有贡献，兼名医），但**幻术情节出自《演义》**。建议在文案或简介中标注「出自《三国演义》第六十八回，正史载有其人而无此事」，兼顾趣味与严谨——这与本系列此前「荀彧/田丰」等偏史实的人物略有不同，需统一口径。
- **调性**：左慈是「**以弱戏强**」的爽感，与本系列惯常的悲情相反，是全系列第一个**带喜剧/解构色彩**的角色，可主动强调「方士戏奸雄」的反差。
- **尺度**：幻术画面宜写意不宜写实（避免血腥的「手提其头」过度渲染），用墨影/青气暗示即可。

## 六、三条选题路线（供决策）

| 方案 | 选题组合 | 打法 | 优点 | 风险 |
|---|---|---|---|---|
| **A（推荐）** | 左慈 → 于吉 → 管辂 → 华佗 | **奇人异士线** | 一口气开全新类型，与水墨契合度最高，差异化最强，且四人天然成组（可再做「三国奇人合集」） | 知名度低于武将，单条流量可能偏弱 |
| **B** | 貂蝉 → 蔡文姬 → 孙尚香 → 黄月英 | **女性线** | 填补最大空白，情感浓度高，易出圈 | 演义中女性多为附庸，素材密度不均（黄月英史料极少） |
| **C** | 张辽 → 甘宁 → 陆逊 → 徐庶 | **延续悲情/东吴线** | 与现有 12 人调性一致，最稳 | 差异化最小，第 4 个「忠而见戮」易审美疲劳 |

**建议：以 A 为主线（先做左慈），穿插 B 的貂蝉作为流量点。** 奇人线负责差异化与视觉升级，貂蝉负责破圈；两者都不与已做 12 人撞型。

## 七、行业趋势佐证（2026）

- **追光动画《三国第一部：争洛阳》**（2026-07-10 上映，《长安三万里》原班人马）：刻意避开赤壁、官渡、桃园结义等经典名场面，选择「极少被影视化的 189 年洛阳乱局」，以**青年曹操/袁绍**视角，主打「去脸谱化」。
- 评论普遍指出：三国 IP 的困境是「**经典叙事已成共识，稍有偏差便招致批评**」；冷门切口既能科普历史，又能挖掘人物早期心路，**是冒险也是突破**。
- **对本系列的启示**：本系列已有的「悲情冷门」调性（祢衡、田丰、陈宫）**正好踩在这个趋势上**，不必急于补关羽、诸葛亮；继续往「冷门但有戏」走，反而更符合当下的破壁逻辑。
- 该片亦采用**中式水墨画风 + 厚重历史**，印证水墨风格在成年观众中的接受度。
